# 📸 Imagens do Convite

Esta pasta contém as imagens usadas no convite digital.

## Imagens Principais

### ✅ Já configuradas:
- **sealed.jpg** - Imagem do envelope fechado/lacrado
- **opening.jpg** - Imagem do envelope abrindo (atualmente usando a mesma imagem de sealed.jpg)

## 🎨 Como Personalizar

### Substituir as Imagens do Envelope

Para usar imagens personalizadas:

1. **sealed.jpg**: Imagem que aparece quando o convite está fechado
   - Ideal: 430px de largura (ou maior)
   - Formato vertical/retrato
   - Sugestão: Foto do envelope físico ou design personalizado

2. **opening.jpg**: Imagem que aparece durante a animação de abertura
   - Mesmas dimensões de sealed.jpg
   - Sugestão: Variação da imagem do envelope ou foto da aniversariante

### Dicas:
- Use ferramentas como Canva, Photoshop ou GIMP para criar/editar
- Mantenha as cores no tema roxo (#4A2C5A) do convite
- Comprima as imagens para web (recomendado < 500KB cada)
